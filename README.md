# Java DSA Week 1 Code Challenge

Follow instruction from Canvas [CC 7.1 - Data Structure Challenge](https://awstechu.instructure.com/courses/803/modules/items/149583)

# Summary
This program will take a list of numbers provided by the user and sort them in the following manner:
- Odd numbers are put in a stack
- Even numbers (including 0) are put in a queue
- Non-numbers are ignored
Once it has finished processing the list, it will then print out the queue in FIFO order and the stack in LIFO order. It also prints the sum of the queue and the sum of the stack.

Note: No error testing file was provided as the program relies on user input. However, the provided screenshot shows a variety of error testing including:
- An empty list
- A list of only non-numbers
- A list of a mix of numbers and non-numbers
- A list with only one value for the queue
- A list with only one value for the stack
